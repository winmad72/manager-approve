# אישור הזמנה – טופס מנהל

עמוד HTML עצמאי (ללא שרת) המאפשר למנהל:

1. להעלות את קובץ ה-PDF של טופס ההזמנה שהתקבל מהטופס המקוון.
2. לחתום דיגיטלית ולהוסיף הערות.
3. ליצור PDF חדש עם החתימה בתחתית העמוד האחרון ועמוד הערות נוסף בסופו, ולשמור/לשלוח אותו.

## הפעלה

הקובץ `index.html` הוא עצמאי ומטעין את הספריות שהוא צריך (pdf-lib, fontkit, גופנים) מרשת ה-CDN.
כדי להריץ אותו מ-GitHub, הדרך הפשוטה ביותר היא **GitHub Pages**:

1. יוצרים ריפו חדש ומעלים את כל תוכן התיקייה הזו (כולל קובצי ה-`.ttf`).
2. ב-GitHub: Settings → Pages → Branch: `main` (או `master`) / Folder: `/ (root)` → Save.
3. אחרי דקה-שתיים הכתובת תהיה בסביבות `https://<username>.github.io/<repo>/`.

אפשר גם פשוט לפתוח את `index.html` מקומית בדפדפן (לחיצה כפולה על הקובץ) – הוא יעבוד ללא שרת,
אבל שמירת קבצים תתבצע כהורדה רגילה של הדפדפן.

## התקנה כאפליקציה (PWA)

הפרויקט כולל `manifest.json` ו-`sw.js`, כך שאחרי שהאתר עולה ב-GitHub Pages (חובה HTTPS – וזה מתקיים
אוטומטית ב-Pages) אפשר "להתקין" אותו כאפליקציה:

- **אנדרואיד (כרום):** נכנסים לכתובת, לוחצים על תפריט שלוש הנקודות → "התקן אפליקציה" / "הוסף למסך הבית".
- **אייפון (ספארי):** כפתור שיתוף → "הוסף למסך הבית".
- **מחשב (כרום/אדג'):** סמל התקנה (+) בשורת הכתובת.

לאחר ההתקנה הטופס ייפתח בחלון עצמאי (בלי סרגל הכתובת של הדפדפן) עם האייקון שנוצר לו.

## מבנה הקבצים

```
index.html                  – העמוד עצמו (HTML/CSS/JS)
manifest.json                – הגדרות ה-PWA (שם, אייקונים, צבעים)
sw.js                        – Service Worker בסיסי, מאפשר התקנה ופעולה אופליין
icon-192.png / icon-512.png  – אייקוני האפליקציה
icon-maskable-512.png        – גרסת אייקון "maskable" לאנדרואיד
NotoSansHebrew-Regular.ttf   – גופן עברי המוטבע ב-PDF שנוצר
NotoSansHebrew-Bold.ttf      – גופן עברי מודגש המוטבע ב-PDF שנוצר
```

הערה: הגרסה הזו זהה לזו שפורסמה כ-Artifact בקלוד, עם הבדל אחד — פונקציית השמירה
(`saveFile()` בתוך `index.html`) מזהה אוטומטית אם היא רצה מחוץ לסביבת ה-Artifact
(כלומר כשמריצים אותה מ-GitHub Pages או מקומית) ובמקרה כזה עוברת להורדה רגילה של
הדפדפן במקום ל-API הפנימי של קלוד. אין צורך בשינוי ידני.
